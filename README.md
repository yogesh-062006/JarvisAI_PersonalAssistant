# 🤖 Jarvis AI Personal Assistant

An AI-powered personal assistant built using Python and LiveKit, with web search capabilities to help retrieve information from the internet.

## 📌 About the Project

Jarvis AI Personal Assistant is a Python-based project designed to explore AI assistant development and real-time agent integration using LiveKit.

The project integrates Gemini AI and web search functionality to retrieve relevant information and provide useful responses.

## ✨ Features

- 🤖 AI-powered personal assistant
- 🔎 Web search functionality
- 🧠 Gemini AI integration
- 🔗 LiveKit agent integration
- 🐍 Python-based implementation

## 🛠️ Technologies Used

- Python
- LiveKit
- Gemini AI
- Web Search
- Python Virtual Environment

## ⚙️ Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/yogesh-062006/JarvisAI_PersonalAssistant.git
cd JarvisAI_PersonalAssistant
```

### 2. Create a Virtual Environment

```bash
python -m venv venv
```

### 3. Activate the Environment

Windows:

```bash
venv\Scripts\activate
```

### 4. Install Dependencies

```bash
pip install -r requirements.txt
```

### 5. Configure Environment Variables

Create a `.env` file in the project directory and add the API keys and configuration values required by your code.

**Security:** Never upload `.env` files, API keys, or other secrets to GitHub.

### 6. Run the Agent

```bash
python agent.py dev
```

Follow the LiveKit configuration and terminal instructions required by your setup.
